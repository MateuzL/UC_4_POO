# SENAC - Gestão Acadêmica

Projeto Flask para apresentação.

## Estrutura
- app.py
- requirements.txt
- templates/
- static/css/style.css
- static/js/script.js

## Executar no Windows
1. Abra o terminal dentro desta pasta.
2. Execute:
   python -m pip install -r requirements.txt
3. Depois:
   python app.py
4. Abra no navegador:
   http://127.0.0.1:5000
